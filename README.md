# 🍰 Landing Page – Confeitaria

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma landing page simples e estratégica para uma confeitaria que deseja estabelecer presença digital e fortalecer sua marca online.

A página tem como principal objetivo apresentar os produtos e a identidade da confeitaria, além de gerar conversões por meio de contato direto via WhatsApp.

---

## 🎯 Objetivos

* Criar presença digital para a confeitaria
* Apresentar produtos e trabalhos realizados
* Comunicar Missão, Visão e Valores (MVV)
* Exibir avaliações de clientes (prova social)
* Converter visitantes em leads via WhatsApp

---

## 🧁 Estrutura da Página

A landing page será composta pelas seguintes seções:

### • Hero Section

* Nome da confeitaria
* Frase de impacto
* Imagem de destaque
* Botão de chamada para ação (CTA) direcionando para o WhatsApp

### • Demonstração dos Produtos

* Galeria com fotos de bolos, doces e kits personalizados
* Layout responsivo em grid

### • Sobre a Confeitaria

* Breve apresentação da história
* Diferenciais
* Posicionamento da marca

### • Missão, Visão e Valores

* Missão
* Visão
* Valores institucionais

### • Blog de Avaliações

* Depoimentos de clientes
* Comentários e possíveis imagens
* Conteúdo estático via JSON ou banco simples

### • Conversão de Leads

* Botão fixo ou destacado com link direto para o WhatsApp
* Foco em facilitar o contato e reduzir fricção na conversão

---

## 🛠️ Tecnologias Utilizadas

O projeto será desenvolvido utilizando:

* **HTML5** – Estrutura semântica da página
* **CSS3** – Estilização e personalização visual
* **JavaScript** – Interatividade e manipulação de dados
* **Bootstrap** – Grid responsivo e componentes prontos
* **Animate.css** – Animações visuais suaves
* **JSON ou Banco de Dados simples** – Armazenamento das avaliações
